# Sources and limits

This bundle contains original workflow guidance and paraphrases, not reproductions of books or third-party skills. Links do not imply endorsement. Historical research informs these rules; this is not a claim that every source was freshly checked for this release or that complete books were read.

| Source | What it informs | Reading/evidence boundary |
| --- | --- | --- |
| Stephen Few, [Formatting and Layout Matter](https://www.perceptualedge.com/articles/Whitepapers/Formatting_and_Layout_Matter.pdf) | Alignment, grouping, meaningful hierarchy | Public paper, not the complete *Information Dashboard Design* book |
| Few, [Dashboard Design](https://www.perceptualedge.com/articles/Whitepapers/Dashboard_Design.pdf) | Monitoring and action-oriented summaries | Public paper; domain-specific guidance needs adaptation |
| Few, [Missing Values and Incomplete Periods](https://www.perceptualedge.com/articles/visual_business_intelligence/missing_values_and_incomplete_periods_in_time_series.pdf) | Honest time comparisons | Public article |
| Few, [Dual-Scaled Axes](https://www.perceptualedge.com/articles/visual_business_intelligence/dual-scaled_axes.pdf) | Scale and comparison hazards | Public article; no blanket chart ban |
| Tamara Munzner, [Visualization Analysis and Design](https://www.cs.ubc.ca/~tmm/vadbook/) and [Nested Model](https://www.cs.ubc.ca/labs/imager/tr/2009/NestedModel/) | Task, data, encoding and validation separation | Author overview and paper abstract, not complete book |
| Claus Wilke, [Fundamentals of Data Visualization](https://clauswilke.com/dataviz/) | Encodings, color and uncertainty | Selected public chapters |
| Edward Tufte, [Envisioning Information](https://www.edwardtufte.com/book/envisioning-information/) | Context, comparison and layered information | Book-level inspiration; no copied text or illustrations, not a full-book review |
| [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Keyboard, contrast, structure and status messages | Selected requirements; bounded testing is not a conformance certification |
| [Cooperative Dashboard Design](https://vis.csail.mit.edu/pubs/cooperative-dashboards/) | Explicit communication and dashboard heuristics | Research overview; not proof this skill improves workplace outcomes |
| [Impeccable](https://github.com/pbakaus/impeccable) | Product-surface craft, coherent typography, interaction and visual inspection | Local skill-v4.7.0 guidance consulted; no bundled upstream code/text or required dependency |
| [P-Stack](https://github.com/cursor/plugins) | Competing structural prototypes when decisions are genuinely unresolved; evidence before quality claims | Local 0.15.36 guidance consulted; no bundled upstream code/text or required dependency |

The MIT license covers this repository's original content only. Referenced works retain their own copyright and licenses. No private project artifacts, source documents, screenshots or customer data are included. Useful design principles are hypotheses to apply and test in context, not universal aesthetic rules.
